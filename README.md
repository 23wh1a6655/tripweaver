# 🌍 TripWeaver – AI-Powered Travel Planning Platform

## Overview

TripWeaver is a full-stack AI-powered travel planning and booking platform designed to simplify trip planning through intelligent recommendations, automated itinerary generation, and seamless booking experiences. The application combines Generative AI, real-time travel services, and social travel features to help users plan personalized trips efficiently.

## Features

### ✨ AI Itinerary Generation

Generate personalized travel itineraries based on destination, budget, duration, and user preferences using Google Gemini AI.

### 💬 AI Travel Chatbot

An intelligent travel assistant powered by Groq that answers travel-related questions, provides recommendations, assists with planning, and automates trip booking workflows.

### 🔍 Destination Discovery

Search and explore destinations, attractions, hotels, and points of interest with detailed information and recommendations.

### 📍 Interactive Maps

Integrated Google Maps and Google Places APIs for location discovery, navigation, and route visualization.

### ✈️ Flight Search

Search and compare flight options through Amadeus API integration.

### 💳 Secure Payments

Book trips securely using Stripe payment gateway integration.

### 📧 Email Notifications

Receive booking confirmations, itinerary updates, and travel notifications via email.

### 👥 Open Trip – Social Travel Feature

Connect with travelers who share similar interests, join group trips, and build travel communities.

### 🎯 Personalized Recommendations

Receive AI-driven destination, activity, and travel suggestions tailored to your preferences.

### 💰 Budget-Based Planning

Generate optimized travel plans that align with your budget constraints.

### 📜 Trip History Management

Access and manage previously planned and booked trips through a personalized dashboard.
